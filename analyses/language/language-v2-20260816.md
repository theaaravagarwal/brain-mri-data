The planner rejected an unauthorized AMD profile, an ambiguous request,
prompt injection, and a request to execute training. Ollama offloaded all
49/49 planner layers; its ROCm model buffer was approximately 17.5 GB. The
longer mean wall times include each model's first cold load.

## Guardrails and limits

- The explainer receives validated, non-identifying structured results and
  frozen source cards only; it never receives MRI pixels or paths.
- The planner can select or abstain from a frozen allowed-job list. It cannot
  execute, modify, or invent jobs.
- These small synthetic gates establish schema adherence and bounded safety
  behavior, not clinical validity, broad robustness, or external
  generalization.
- Fine-tuning is not justified by this result because every predeclared gate
  passed. The next useful experiment is broader held-out/adversarial evaluation,
  not immediate LoRA training.
